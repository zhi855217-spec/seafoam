# 🐻 Seafoam 文创工作台

八月文创产品（贴纸 / 卡片 / 徽章 / 散卡等纸制品）销售管理工作台。  
单页 PWA 应用，可安装到手机桌面，离线可用。

## ✨ 功能

- **首页驾驶舱**：今日销售额/利润/利润率、本月累计支出（细分约稿费/包材/推广/赠品/采购/其他）、热销 Top3、库存与约稿预警
- **产品管理**：SKU 自动生成、双图上传、分类层级、材质/用途标签、成本构成明细、安全库存线、产品状态
- **销售记录**：自动扣库存、自动算利润、支持单品 / 套组两种类型、多渠道（微店/小红书/淘宝/闲鱼/线下市集/朋友圈）
- **智能定价**：选产品自动带入成本，约稿成本池可勾选特定稿件，按件数/销售额分摊，定价历史记录
- **采购进货**：记录每次进货，自动加库存，可选更新产品成本，影响定价
- **分装**：散卡拆包成不同规格成品，自动扣散卡库存、按比例分摊成本到成品
- **组合套组**：创建套组卖出时一次性扣减所有子产品库存
- **约稿 / 包材 / 供应商 / 费用** 等独立模块管理
- **CSV 数据导出**：按月导出销售报表（Excel 兼容）
- **PWA**：可"添加到主屏幕"，离线可用，Chiikawa 卡通海泡绿主题

## 🚀 GitHub Pages 部署

1. Fork 本仓库
2. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`
3. 访问 `https://<用户名>.github.io/<仓库名>/`

## 📱 手机安装

用手机浏览器打开部署后的地址 → 浏览器菜单 → "添加到主屏幕" → 像 App 一样使用。

## 🗂 文件结构

```
index.html              # GitHub Pages 入口（= app.html）
app.html                # 本地入口（备用）
sw.js                   # Service Worker（缓存策略：网络优先）
manifest.json           # PWA 配置
icon-192.png            # PWA 图标
icon-512.png            # PWA 图标
icon-maskable-512.png   # Android adaptive icon
apple-touch-icon.png    # iOS 图标
```

## 💾 数据

所有数据存在浏览器 localStorage（key: `seafoam_v4`），不上传任何服务器。
建议定期通过「更多 → 📊 导出」备份 CSV。
